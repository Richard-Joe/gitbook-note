## 基础概念

| 概念 | 一句话解释 |
|------|-----------|
| **大模型 (LLM)** | 通过海量文本训练出的"超级预测机器"，能根据前文预测下一个词，从而生成连贯内容。 |
| **Transformer** | 当前AI的基石架构，用"注意力机制"让模型同时关注句子中所有词的关系，而非逐个阅读。 |
| **注意力机制 (Attention)** | 让模型自动判断"这个词应该更关注哪些其他词"，类似人阅读时会来回扫视重点。 |
| **Token** | 模型处理文本的最小单位（可能是1个汉字、1个单词或1个标点），是计费和长度的基本单元。 |
| **参数 (Parameters)** | 模型内部的"可调旋钮"，数量越多（如70B=700亿），理论上存储的知识和能力越强。 |
| **推理 (Inference)** | 模型已经训练好，用户使用时输入问题、输出答案的过程（区别于"训练"）。 |


## 训练相关

| 概念 | 一句话解释 |
|------|-----------|
| **预训练 (Pre-training)** | 用海量互联网文本让模型学会语言规律和世界知识，类似"通识教育"。 |
| **微调 (Fine-tuning)** | 在预训练基础上，用特定领域数据（如医疗、法律）专门训练，让模型成为"专科生"。 |
| **RLHF (人类反馈强化学习)** | 让人给模型回答打分，模型学习"说什么话人类更喜欢"，从而对齐人类价值观。 |
| **涌现能力 (Emergence)** | 模型规模突破某个临界点后，突然展现出小模型没有的能力（如推理、算术），类似量变引起质变。 |
| **幻觉 (Hallucination)** | 模型自信地编造看似合理但实际错误的信息，因为它本质是"预测下一个词"而非"查资料"。 |


## 模型类型

| 概念 | 一句话解释 |
|------|-----------|
| **RAG (检索增强生成)** | 模型回答前先查资料库，把找到的相关内容塞进提示词，用"开卷考"减少幻觉。 |
| **Agent (智能体)** | 能自主规划、调用工具（搜索、代码、API）并多步骤完成任务的大模型系统。 |
| **多模态 (Multimodal)** | 能同时理解/生成文本、图像、音频、视频等多种类型数据的模型。 |
| **MoE (混合专家)** | 把模型拆成多个"专家子模型"，每次只激活部分专家，用更少算力获得更大模型效果。 |
| **蒸馏 (Distillation)** | 让大模型当老师、小模型当学生，把小模型训练得接近大模型能力，实现轻量化。 |


## 工程部署

| 概念 | 一句话解释 |
|------|-----------|
| **上下文窗口 (Context Window)** | 模型能"记住"的输入长度限制（如128K tokens），超出部分会被遗忘或压缩。 |
| **量化 (Quantization)** | 把模型参数从高精度（如FP32）转为低精度（如INT8），牺牲少量精度换取大幅显存节省。 |
| **推理加速/优化** | 通过缓存、并行、剪枝等手段让模型生成答案更快、更省资源。 |
| **Prompt Engineering** | 通过精心设计输入问题的措辞和格式，引导模型输出更好的答案，无需改动模型本身。 |

## 推理

| 概念                              | 一句话解释                                                         |
| ------------------------------- | ------------------------------------------------------------- |
| **思维链 (Chain-of-Thought, CoT)** | 让模型把"思考过程"写出来再回答，类似解数学题时写出步骤，能显著提升复杂推理的准确性。                   |
| **ReAct (Reasoning + Acting)**  | 让模型**边思考边行动**——先想下一步该做什么，再调用工具（搜索/代码/API），观察结果后继续思考，循环直到解决问题。 |

## 工具

| 概念                               | 一句话解释                                                            |
| -------------------------------- | ---------------------------------------------------------------- |
| **MCP (Model Context Protocol)** | AI 世界的"USB-C 接口"——统一标准让大模型能即插即用连接各种外部工具和数据源，无需为每个工具单独开发适配。       |
| **Skills (技能)**                  | 给 AI 预设的"工具包"或"专业本领"，封装了完成特定任务的能力（如查天气、写代码、调API），让模型知道何时调用、如何执行。 |
