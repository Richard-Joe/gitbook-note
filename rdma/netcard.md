# 网卡主要组成部分及其作用

## 一、硬件数据通路（纯硬件逻辑，线速处理每个数据包）

| 组件 | 作用 |
|------|------|
| **PHY（物理层）** | 处理模拟信号：编码/解码、串行/解串、自动协商链路速度（10/100/1000/10G等）、检测链路状态、管理双工模式和MDI/MDIX极性。 |
| **MAC（媒体访问控制）** | 以太网帧的封装与解封装、介质访问控制（CSMA/CD/全双工）、地址过滤、CRC校验与生成、流量控制（PAUSE帧）。 |
| **FIFO / 片上缓冲区** | 小容量SRAM，用于匹配网络线路速率与PCIe总线速率，暂存一个或多个数据包，解决速度匹配和突发传输问题。 |
| **DMA 控制器** | 硬件状态机，负责在网卡FIFO与系统内存（描述符环指向的数据缓冲区）之间高速搬运数据。完全由硬件执行，不经过固件，是实现高性能收发的关键。 |
| **描述符 / 队列管理逻辑** | 自动解析主机内存中的描述符环（环形队列），读取发送描述符获得数据地址和长度，或写入接收描述符状态。支持多队列（RSS/Flow Director）实现负载均衡。 |
| **PCIe 接口逻辑** | 实现PCIe事务层、数据链路层、物理层，处理地址路由、流量控制、ACK/NAK等。DMA控制器通过它读写系统内存，驱动通过它访问网卡寄存器。 |

## 二、控制与管理子系统（运行固件，负责配置、异常处理、高级卸载）

| 组件 | 作用 |
|------|------|
| **嵌入式处理器** | 网卡内部的小型CPU（ARM/MIPS/专用RISC），运行固件代码。不干预每个包的数据搬运，但负责初始化硬件、处理异常（链路抖动、DMA超时）、响应驱动命令（ethtool、VLAN配置）、管理电源、监控温度等。 |
| **固件（Firmware）** | 存储在NVM中的程序，运行在嵌入式处理器上。实现自动协商策略、PHY调优、错误恢复流程、SR-IOV虚拟化配置、RDMA/RoCE拥塞控制、协议卸载引擎（TSO/LRO/VXLAN）的行为参数等。 |
| **NVM / EEPROM / Flash** | 非易失性存储器，永久保存固件二进制代码、MAC地址、PCIe能力配置、PHY校准参数、供应商特定信息。网卡固件更新就是修改NVM中的程序。 |

## 三、主机侧软件（不在网卡上，但不可或缺）

| 组件 | 作用 |
|------|------|
| **设备驱动程序** | 运行在操作系统内核（如Linux），负责：分配和初始化描述符环、设置DMA地址映射、处理中断、调用NAPI、配置网卡寄存器、与固件通过mailbox通信、实现net_device接口。 |

### 驱动程序中的 DMA 核心逻辑

驱动对 DMA 的管理可归纳为以下 7 个方面：

| 职责 | 说明 |
|------|------|
| **1. 分配与映射 DMA 缓冲区** | 分配物理内存（连续或非连续），将内核虚拟地址转换为硬件可识别的总线地址，处理 IOMMU 映射，维护缓存一致性（冲刷/作废 Cache）。 |
| **2. 设置描述符环** | 在内存中创建描述符环形队列，填充缓冲区地址、长度、标志等，将描述符环基地址写入硬件寄存器，更新生产者/消费者指针（Tail/Head）。 |
| **3. 启动与停止 DMA** | 通过 MMIO 写网卡寄存器的"发送/接收使能"位，控制 DMA 控制器的运行状态。 |
| **4. 中断处理与轮询** | 响应 DMA 完成中断，读取状态寄存器，更新软件描述符索引，回收已用缓冲区，调用网络协议栈接收函数，重新填充空缓冲区。 |
| **5. 错误恢复** | 检测 DMA 超时或错误（PCIe 链路故障、地址越界等），复位 DMA 引擎，清空描述符环，重新初始化硬件。 |
| **6. IOMMU/SMMU 交互** | 为设备分配 IOMMU 域，建立设备到内存的地址映射，管理 IOVA，防止设备 DMA 访问任意物理内存，提高安全性。 |
| **7. 提供统一 DMA API** | 封装体系结构差异（x86, ARM, PowerPC）和总线类型差异（PCI, platform, USB），驱动通过 `dma_alloc_coherent`、`dma_map_single` 等 API 使用 DMA 功能。 |

## 关系说明

- **硬件数据通路** 负责每个数据包的线速收发，完全由硬件自动完成，**固件不参与**。
- **控制管理子系统** 负责网卡的启动、异常恢复、策略配置和高级卸载，**不干预数据通路**。
- **驱动程序** 作为主机与网卡之间的中间层，协调两者工作。

> 现代普通网卡（PCIe接口）必然包含上述硬件数据通路各组件，以及一个最小化的控制管理子系统。集成网卡或智能网卡可能将部分功能（如嵌入式处理器）做得更强大，但基本架构一致。
